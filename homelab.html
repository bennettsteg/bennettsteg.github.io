The server

Select a component on the case to see what it is.

CPU

AMD Ryzen 7 5700G

The processor that runs every service on the server: 8 cores and 16 threads, with integrated Radeon graphics so no separate GPU is needed.

RAM

Corsair Vengeance DDR4 16GB

Working memory for the server's services and virtual machines.

Cooler

Thermalright Assassin X120

A single-tower air cooler with a 120 mm fan that keeps the CPU at a steady temperature.

Motherboard

GIGABYTE B550M AORUS Elite AX

A micro-ATX AM4 board with built-in Wi-Fi 6 that connects the CPU, memory, storage, and network.

M.2 SSD

Samsung 9100 PRO 1TB

A fast NVMe drive that holds the operating system and the services that need quick storage.

Power supply

Corsair RM750e

A 750 W fully modular power supply, so only the cables the build needs are plugged in.

Drive bay

Seagate IronWolf 4TB

Bulk storage behind the wooden front door. It's a single NAS-rated hard drive for now, with room in the case to add more.
