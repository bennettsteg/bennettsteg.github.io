The server

CPU

AMD Ryzen 7 5700G

The processor that runs every service on the server: 8 cores and 16 threads, with integrated Radeon graphics so no separate GPU is needed.

RAM

Corsair Vengeance DDR4 16GB

Working memory for the server's services and virtual machines.

Cooler

Thermalright Assassin X120

A single-tower air cooler with a 120 mm fan that keeps the CPU at a steady temperature.

Motherboard

GIGABYTE B550M AORUS Elite AX

A micro-ATX AM4 board with built-in Wi-Fi 6 that connects the CPU, memory, storage, and network.

M.2 SSD

Samsung 9100 PRO 1TB

A fast NVMe drive that holds the operating system and the services that need quick storage.

Power supply

Corsair RM750e

A 750 W fully modular power supply, so only the cables the build needs are plugged in.

Drive bay

Seagate IronWolf 4TB

Bulk storage behind the wooden front door. It's a single NAS-rated hard drive for now, with room in the case to add more.

Proxmox VE

Hypervisor

The foundation of the homelab. Proxmox runs directly on the server hardware and hosts everything else as virtual machines and containers: a Docker VM and a small streaming container.

Docker VM

Virtual machine · on Proxmox

The main virtual machine. It runs Tailscale for remote access and Docker, which hosts all nine services.

Streaming container

Lightweight container · on Proxmox

A small, lightweight container that streams to my TV using Moonlight.

Tailscale

VPN · in the Docker VM

Puts the Docker VM on my private Tailscale network, so I can reach my services securely from anywhere.

Docker

Container runtime · in the Docker VM

Runs each service as an isolated container, grouped into nine stacks, and managed with Portainer.

Portainer

Docker management · in Docker

A web interface for managing Docker: stacks, containers, images, and volumes, all from the browser.

Homepage

Docker stack · in Docker

A dashboard that puts links and status for all my services on one page.

Nextcloud

Docker stack · in Docker

Self-hosted file sync and storage: my own cloud for files, calendars, and contacts.

Nginx Proxy Manager

Docker stack · in Docker

A reverse proxy with a web interface. It routes each service's address to the right container and handles SSL certificates.

pgAdmin

Docker stack · in Docker

A web interface for managing and querying PostgreSQL databases.

Pi-hole

Docker stack · in Docker

A network-wide DNS sinkhole that blocks ads and trackers for every device that uses it for DNS.

Postgres

Docker stack · in Docker

The PostgreSQL database server, for the services that need a relational database.

Student Dashboard

Docker stack · in Docker

My StudyDesk dashboard, self-hosted. It brings my assignments, courses, notifications, and schedule together in one place. It's also on the Projects page.

Study Tool

Docker stack · in Docker

My practice-test app for studying. I build tests from course chapters, take them, and review my attempts.

Beszel

Docker stack · in Docker

A lightweight monitoring hub that tracks CPU, memory, disk, and container stats for the server.
