# Portfolio Site

A personal portfolio published via GitHub Pages, showcasing projects, current work, interests, and technical skills. Content grows continuously over time.

## Language

**Project**:
A concrete, named piece of work with its own identity — typically something shippable or linkable (a repo, a built artifact, a deployed app). Shown on the Projects page.

**Now**:
What you're currently working on or exploring. Broader and more ephemeral than a Project — doesn't require a shippable artifact (e.g. a topic you're learning, not necessarily a thing you've built). Kept as a separate collection from Project rather than a status flag on it, so it can hold things that never become projects.
_Avoid_: using "Project" with a `status: active` field to mean this — conflates two different kinds of thing.
